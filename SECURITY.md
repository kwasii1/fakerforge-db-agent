# Security Policy

## Supported Versions

Only the latest GitHub Release is supported with security updates. Check
your version with `fakerforge version` and upgrade if you are behind.

## Reporting a Vulnerability

**Do not open a public issue for security problems.** Instead, use one of
these private channels:

1. **GitHub private vulnerability reporting** (preferred): open the
   repository's Security tab → "Report a vulnerability". This creates a
   private advisory visible only to you and the maintainers.
2. **Email**: kesbijnr@gmail.com with subject `[fakerforge security]`.

Include: the affected version (`fakerforge version` output), your OS and
architecture, steps to reproduce, and the impact you see. Log output and
config help — redact API keys, DB passwords, and connection details first.

We aim to acknowledge reports within 3 business days and will keep you
updated until a fix is released. Once fixed, we publish the patch as a new
release and credit you in the advisory unless you prefer to stay anonymous.
